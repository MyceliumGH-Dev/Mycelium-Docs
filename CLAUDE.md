# CLAUDE.md

Component documentation site for Mycelium (MkDocs Material). Primary deployment is Netlify
at https://mycelium-gh-docs.netlify.app; `deploy.yml` also publishes a `gh-pages` mirror
from `main`. The marketing site is a **separate** repo: `MyceliumGH-Dev/Mycelium-Website`.

## Branch model — read before pushing

- **`dev` is the working branch**: land all changes here directly.
- **`main` is the published branch**: nothing on `dev` is visible on the live site until a
  `dev → main` PR is merged.
- Publishing flow: push `dev` → `gh pr create --base main --head dev` →
  `gh pr merge --merge`.

## Generated vs hand-written

**Generated by `tools/export_components.py` — do not hand-edit:**

```
docs/components/*.md   docs/categories/*.md   docs/Components.md
docs/toolbar.md        docs/components_nav.yml
docs/images/icons/*    docs/images/components/*
```

**Hand-written:** `docs/index.md`, `docs/first_steps.md`, `mkdocs.yml`,
`docs/stylesheets/extra.css`, `docs/overrides/main.html`.

Regeneration (`tools/generate_docs.sh`) drives a real Rhino 8 + Grasshopper session to
capture canvas screenshots, so it only runs on a machine with Rhino installed and a
logged-in desktop. It cannot run in CI. `--check` turns it into a drift detector.

The export walks `Grasshopper.Instances.ComponentServer.ObjectProxies` for everything in
the `Mycelium` category, so **the installed plug-in version is what gets documented** —
install the build you intend to publish docs for before regenerating.

Panel order comes from `CATEGORY_ORDER` in `tools/export_components.py`, not from
alphabetical sorting; add new panels there or they land at the end.

## Release coupling

On every Mycelium plugin release (`MyceliumGH-Dev/Mycelium`, `manifest.yml` version):

- `mkdocs.yml` → `extra.latest_mycelium_version` pin.
- Re-run `tools/generate_docs.sh` if components, descriptions, or IO changed.
- Then the `dev → main` PR — the release is not done until it merges.

## Conventions

- Palette lives in `docs/stylesheets/extra.css`; `mkdocs.yml` declares `primary: custom` /
  `accent: custom`. It is a copy of the website's palette plus the component-doc blocks
  (nav icons, quick-link cards, ribbon toolbar) — keep the shared part in sync by hand.
- Generated pages use root-absolute asset paths (`/images/icons/...`), which only resolve
  in a built site served from a domain root. `.lycheeignore` exempts them from the link
  checker. Consequence: **the gh-pages mirror at `/Mycelium-Docs/` shows no icons or
  screenshots** — Netlify is the canonical URL until a custom domain exists. Do not
  "fix" this by rewriting generated pages; the next export overwrites them.
